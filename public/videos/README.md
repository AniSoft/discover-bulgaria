# Home page cinematic video

Drop the licensed Bulgaria footage here using exactly these filenames:

- `bulgaria-cinematic.webm` (preferred — VP9/AV1, ~6–10s loop, no audio track)
- `bulgaria-cinematic.mp4` (H.264 fallback)

Recommended: 1920x820-ish cinematic crop, under ~4 MB, muted, seamless loop.

Until these files exist, the section renders the poster photograph only —
no code changes are required when the footage is added.
